(레퍼런스인 연세대 사례도 상담센터 측이 후기를 '공유'하는 구조) **채택안**: 학생이 후기 작성 → 본인 화면에는 "제출 완료! 검토 후 게시됩니다" 즉시 표시 → 9월 초~10월 초 승인제 시범운영 (관리자/팀이 돌아가며 주 N회 기준으로 승인 후 게시) ### 실제 운영 고려사항 1. **콜드 스타트**: 오픈 첫날 후기 0개보다 어느 정도 목록이 있는 게 유리. 지인 위주 초기 수집(+에타 후기 재구성)으로 채우되, 오픈 전 최소 개수(예: 10개)를 미리 정해두기. 2. **자동 필터** (검토 부담 완화용 보조 장치, 네이버 클린봇과 유사한 개념): 제출 즉시 욕설·위기 키워드(자살·자해 관련)를 1차로 걸러줌. 구현 가능 시 시도. - 흐름: 구글폼 응답 → 구글시트 자동 저장 → Google Apps Script(무료, 서버 관리 불필요)로 새 응답마다 자동 실행 → 키워드 필터 통과 시 "게시" 표시, 위기 키워드 감지 시 구글 메일로 자동 알림 3. **다양성/품질**: 제출 폼에 상담 유형(개인상담/심리검사/집단상담) 필수 선택 → 유형별 자동 분류. 작성일 자동 표시로 최신/과거 구분. 4. **신뢰 신호**: "학생이 직접 제출했고, 신상노출·명예훼손 등 최소 기준만 검토 후 게시됩니다" 고지 문구로 필터링 원칙 명시. 현재 게시된 후기 수 카운터("현재 N건") 추가. 5. **인계 문서화** (팀 활동 종료 후에도 지속 가능하도록): 검토 기준(상담사 특정 정보 마스킹, 인신공격 표현 순화 등), 자동 필터 키워드 목록·설정을 깃허브 레포에 문서로 정리. 6. **한계**: 자동 필터는 신조어/상담사 초성만 사용/우회 표현 등을 못 잡음. Google Apps Script 무료 계정은 일일 실행 시간·트리거 횟수·외부 API 호출 횟수 제한 있음 → 자동화는 마지막 단계에 시범 도입. ### 클로드 AI 제안 — 카테고리 통합 사다리타기(상담신청)와 이용후기 필터가 같은 "상담 유형" 카테고리를 공유하도록 통일: - **학습상담 / 진로·취업상담 / 심리상담 / 창업상담 / 집단상담** — 5개를 한 번만 정해서 사다리타기·이용후기 폼 두 곳에 그대로 사용 - 장점 1. 이용후기 게시판에 "학습상담 후기만 보기" 같은 필터를 쉽게 추가 가능 2. 유형 추가/수정이 필요해도 한 곳만 고치면 됨 3. 개발도 한 번에 처리 가능 - 단, "지금 많이 위급해요" 버튼은 후기 유형이 아니므로 이 카테고리에 넣지 않고 위기상담 연락처로 바로 연결 ## 프로토타입과의 매핑 | 기획안 항목 | 프로토타입 파일 | |---|---| | 홈 / 4개 메인 탭 | `index.html` | | 마음 관리 | `pages/mind-care.html` | | 우리 학교 상담 알아보기 (허브) | `pages/counsel-info.html` | | 상담사 소개 | `pages/counselors.html` | | 비밀보장 및 개인정보 보호 | `pages/privacy.html` | | 센터 운영 프로그램 안내 | `pages/programs.html` | | FAQ | `pages/faq.html` | | 상담 신청부터 진행까지 (사다리타기 포함) | `pages/apply.html` | | 이용후기 (필터 + 카운터) | `pages/reviews.html` | | 교외 도움 찾기 | `pages/external-help.html` | | 사다리타기 ↔ 이용후기 카테고리 통합 로직 | `js/main.js` (`LADDER_MAP`) | **아직 구현하지 않은 것** (V2 또는 별도 논의 필요): 실제 구글폼/Apps Script 연동, 자동 키워드 필터, 이룸/딜라이트 실제 신청 링크, 마음관리 실제 콘텐츠(우울/불안/외로움), 상담사 실명 프로필.
